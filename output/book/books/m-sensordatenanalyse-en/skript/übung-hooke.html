63  Exercise: Hooke’s Law

Sensor data often come in multiple files. Possible reasons for this include measurements being taken

  • by different people,
  • at different locations,
  • at different times,
  • using different devices, or
  • for different measurement quantities.

In the folder ‘01-daten/hooke’, there are several txt files containing measurements of spring extension. In this chapter, you will apply what you have learned so far and answer the following questions:

  1. Are there any invalid measurements?
  2. What values can be determined for the spring constants?
  3. Were the measurements taken with the same spring (or with springs of the same spring constant) if a confidence level of 90% or 95% is assumed?

In section Section 63.1 you will find guidance, and in section Section 63.2 a sample solution for reading the files. Afterwards, you are expected to work on the tasks independently. Section Section 63.3 provides a sample solution for data preprocessing. Section Section 63.4 contains the sample solution for determining the spring constants.

Note: Depending on the approach chosen, different results may arise (for example, when evaluating and handling extreme values / outliers).

63.1 Reading Files

To read files, you can use the glob module (see Module on Reading Structured Datasets).

First, you can pass the argument pathname = * to the function glob.glob(). The wildcard * stands for any sequence of characters (except path elements like / or .), allowing you to list all files stored in the specified folder. This way, you can determine the number of files and their extensions if they are not yet known.

folder_path = '01-daten/hooke'

file_path_list = glob.glob(pathname='*', root_dir=folder_path, recursive=False)
print(file_path_list)

63.2 Task: Reading Files

Now read in the files. While doing so, check:

  • whether the data types are correctly interpreted, and
  • for missing values.

You can:

  1. Read each file individually.
  2. Use the glob module to read the files automatically and store each in a separate object (Note: This approach is demonstrated in the Module on Reading Structured Datasets).
  3. Use the glob module to read the files automatically and merge them into a single file.

These options require increasing levels of programming effort. The more separate files you want to analyze, the more automation is needed. Since sensor data analysis often involves numerous files, the model solution shows variant c).

Tip 63.1: Step-by-Step Approach

Reading the files is likely to be the most time-consuming and error-prone step. Develop your solution step by step. Start with variant a). Once you have read the files, you can familiarize yourself with variant b) using the glob module. Building on that, variant c) allows you to automate the process for any number of files.

In the next step, the data will be checked and, if necessary, cleaned. This includes the following steps:

  • checking for outliers (using studentized z-scores and visually) and cleaning if necessary,
  • normalizing the distance measurement to the zero point and converting the units used to SI units, and
  • graphical representation.
Warning 63.1: glob, pd.groupby, and SciPy

The execution of the following code may vary locally, depending on the order in which files are read using the glob module. In the following, index positions in a groupby object are determined where a condition is true. These index positions are then used to access the original DataFrame. Pandas sorts the groups in a groupby object alphabetically by default (sort=True). If the files read with glob are not in alphabetical order, incorrect index positions may be used to access the DataFrame.

This can be avoided either by sorting the DataFrame according to the groupby criteria or, as shown here, by using the argument pd.groupby(by=condition, sort=False). The latter approach is more flexible.

Also, scipy.stats.zscore() may return either a pd.Series or a np.array depending on the version. Accordingly, methods from Pandas or NumPy should be used.

Tip 63.4: Approach for Large Numbers of Datasets

When dealing with a large number of datasets, graphical inspection alone can reach its limits. In this case, it is recommended to combine visual and metric-based methods to identify patterns and verify them across many measurements. For example, after a visual inspection of measurement series with extreme values or outliers, all series could be checked to see if the mean spring elongation increases with increasing weight, as expected. Deviating series could then be further checked graphically.
