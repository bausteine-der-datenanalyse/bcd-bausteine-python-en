60  The Normal Distribution

As the sample size increases, the estimate of the expected value becomes more accurate. Mathematically, this observation is explained by the central limit theorem. For example, when rolling multiple dice, outcomes far from the expected value become increasingly unlikely. This can already be demonstrated with just a few dice (see example).

Note 60.1: Frequency Distribution of Dice Outcomes

For a single die, there are 6 possible outcomes; for 2 dice, 6 * 6 possible combinations; for 3 dice, 6 * 6 * 6 combinations, and so on. Because many combinations have the same total value, results near the expected value occur more frequently than, for example, rolling all ones.

The convergence of measurements toward a population mean as the sample size increases also holds when the population mean and variance are unknown. As the sample size grows, the measurements approach the normal distribution, which is also known as the Gaussian bell curve after its discoverer, Carl Friedrich Gauss.

The convergence of the distribution of measurements to the normal distribution for larger samples can be illustrated using the body mass of penguins from the palmerpenguins dataset.

The normal distribution is a density curve that a histogram approaches as the number of measurements goes to infinity and the class width approaches zero.

Important 60.1: Histogram

A histogram is a graphical representation of the frequency distribution of cardinally scaled variables (i.e., with numerical, ordered values). The data are divided into classes, which can have either constant or variable widths. Adjacent rectangles are drawn with the width of each class, and the area of each rectangle represents the (relative or absolute) class frequency. The height of each rectangle then represents the (relative or absolute) frequency density, i.e., the (relative or absolute) frequency divided by the width of the corresponding class.

Note 60.2: Calculating and Visualizing a Histogram

As an example, we use the length of the tooth-forming cells of guinea pigs that received a vitamin C dose of 2.

dose2 = guinea_pigs.loc[guinea_pigs['dose'] == 2, 'len']

The function np.histogram(a, bins = 10, range = None, density = None) can be used to compute a histogram.

  • a is the data to be analyzed
  • bins specifies the number of bins (classes); by default, 10 bins are used.
  • range = (float, float) allows setting the lower and upper limits of the bins.
  • density = True allows representing the value as the probability density function instead of absolute frequencies. This is calculated as follows:
    • relative frequency = number of values per bin / total number of values
    • probability density = number of values per bin / (total number of values * bin width)
    • bin width = (maximum value - minimum value) / number of bins

For a manageable number of values, a histogram with 5 bins is computed. For comparison, the probability density is also displayed.

print(np.histogram(dose2, bins = 5))
print("Probability density:", np.histogram(dose2, bins = 5, density = True)[0])
(array([2, 5, 8, 2, 3]), array([18.5 , 21.58, 24.66, 27.74, 30.82, 33.9 ]))
Probability density: [0.03246753 0.08116883 0.12987013 0.03246753 0.0487013 ]

The function np.histogram() returns an array of absolute frequencies or frequency densities for each bin as the first output. The second output is an array of the x-positions of the bin edges — for each bin, the position of the left edge is given, and for the last bin, the position of the right edge is also included. For 5 bins, this results in 6 edge positions.

The bin width can be obtained, for example, using the np.diff() method.

hist_abs, bin_edges = np.histogram(dose2, bins=5)
bin_width = np.diff(bin_edges)
print(bin_width)
[3.08 3.08 3.08 3.08 3.08]

By multiplying the frequency density by the class width, the relative frequencies can be calculated.

hist_density = np.histogram(dose2, bins=5, density=True)[0]
hist_relative = hist_density * bin_width
print(hist_relative)
[0.1  0.25 0.4  0.1  0.15]

The function returns 3 values: the absolute frequency of the bins (or, if density=True, the probability density), the x positions of the rectangles, and the objects used for plotting (the latter are stored in the variable ignore in the code below and are not used further).

The probability density function (PDF) of the normal distribution describes the proportion of values that lie within a specific range. When calculating relative frequencies in Note 60.2, we saw that the sum of relative frequencies is 1. This corresponds to the area under the density curve.

The probability density function of the normal distribution is defined as:

\[ f(x) = \frac{1}{\sigma \sqrt{2\pi}} ~ e^{-\frac{1}{2}\left(\frac{x - \mu}{\sigma}\right)^2} \]

The shape of the normal distribution is determined by the factor \(e^{-\frac{1}{2}\left(\frac{x -\mu}{\sigma}\right)^2}\) in the function. The maximum of the function occurs at \(x = \mu\). From there, it decreases symmetrically and approaches the x-axis. The decline of the function is faster when \(\sigma\) is smaller. The inflection points of the curve are located one standard deviation away from the mean.

A normal distribution with mean \(\mu = 0\) and standard deviation \(\sigma = 1\) is called the standard normal distribution.

[@Baitsch-2019, pp. 51-54]

 

60.1 Adjusting a Normal Distribution

To approximate the distribution of a dataset with a normal distribution, its mean and standard deviation are inserted into the normal distribution’s function. In Python, these calculations can be performed directly. More convenient are the functions provided by the SciPy package, which will be presented in detail in the next section. The following example shows calculation and visualization using Python and SciPy.

Note 60.3: Calculating and plotting density curves

Let’s consider the distribution statistics of the group of guinea pigs that received a dose of 2 milligrams of vitamin C.

print(distribution_characteristics(dose2), "\n");

dose2_mean = distribution_characteristics(dose2, output = False)[1]
dose2_std = distribution_characteristics(dose2, output = False)[4]

print("Exact standard deviation:", dose2_std)

If we insert the standard deviation and the arithmetic mean into the normal distribution function, we get:

\[ f(x) = \frac{1}{3.7742 \sqrt{2\pi}} ~ e^{-\frac{1}{2}\left(\frac{x-26.10}{3.7742}\right)^2} \]

\[ f(x) = 0.1057 \cdot e^{-\frac{1}{2}\left(\frac{x-26.10}{3.7742}\right)^2} \]

In Python, these calculations can be implemented and visualized:

60.2 The SciPy Package

Functions for calculating density curves can be imported via the SciPy package. The stats module (statistical functions) includes numerous functions for hypothesis testing. Functions for the normal distribution are called as follows:

import scipy
print("Probability density of the normal distribution at x = 0:", scipy.stats.norm.pdf(0), "\n")
Probability density of the normal distribution at x = 0: 0.3989422804014327

For the normal distribution, four functions are relevant:

Description The function scipy.stats.norm.pdf(x) calculates the density of the normal distribution at the point x (pdf = probability density function). x can also be an array — the curve on the left was calculated using the command scipy.stats.norm.pdf(np.linspace(-4, 4, 100)).

Description
The function scipy.stats.norm.cdf(x) calculates the proportion of values to the left of x (cdf = cumulative density function).

Description
The function scipy.stats.norm.ppf(q) is the quantile function of the normal distribution and the inverse of the cumulative density function (cdf). The function computes, for \(0 \le q \le 1\), the value x to the left of which the proportion q of all values lies and to the right of which the proportion 1-q lies (ppf = percentile point function).

Description
The function scipy.stats.norm.rvs(size) draws size random numbers from the normal distribution.
Note: The random numbers are generated dynamically in the script.

The shape of the normal distribution can be adjusted using the parameters loc = mean and scale = standard_deviation. By default, the standard normal distribution with loc = 0 and scale = 1 is used. The function parameters can be single values (scalars) or arrays/lists.

60.4 Confidence Intervals

Inferential statistics is based on the principle of drawing conclusions about the true population value from sample values. The reasoning is as follows:

  1. When a sample is drawn from a population, the sample values are normally distributed around the population mean. For a normal distribution:

    • 68.27% of all values lie within \(\pm 1 ~ s\),
    • 95.45% of all values lie within \(\pm 2 ~ s\), and
    • 99.73% of all values lie within \(\pm 3 ~ s\).

  2. With the same probability distribution, the unknown population mean is distributed around a random value from the sample.

  3. The expected value can be estimated with a certain probability using the standard error of the mean of a sample. A confidence level is chosen, i.e., the probability that the expected value actually lies within the estimated range. The opposite case, where the expected value does not lie within the estimated range, is called the significance or alpha level, denoted by the Greek letter \(\alpha\). \(\alpha\) ranges from 0 to 1, and the confidence level is \(1 - \alpha\) (see: Type I and II errors).

    • the expected value lies in 68.27% of cases within \(\pm 1 ~ \frac{s}{\sqrt{n}}\),
    • the expected value lies in 95.45% of cases within \(\pm 2 ~ \frac{s}{\sqrt{n}}\), and
    • the expected value lies in 99.73% of cases within \(\pm 3 ~ \frac{s}{\sqrt{n}}\).

Often, the alpha level \(\alpha = 0.05\) or a 95% confidence interval is chosen, which corresponds to \(\pm 1.96 ~ \frac{s}{\sqrt{n}}\). This, however, applies only to large samples. For small sample sizes, sample means follow the t-distribution, which will be introduced in the next section.

In a normal distribution, values near the expected value occur more frequently than values far from it. How often or rarely a value occurs relative to the mean can be expressed using the standard deviation.

A single measurement from the distribution almost never equals the expected value. However, one knows that values close to the expected value occur more frequently than those far away.

The mean of a sample almost never equals the expected value. 60.5 The t-Distribution

The t-distribution was discovered by William Sealy Gosset (though not the very first) and popularized. It is also known as Student’s t-distribution: Since Gosset’s employer, the Guinness Brewery, did not allow him to publish the discovery, Gosset published under the pseudonym Student. (Wikipedia)

The t-distribution describes the distribution of sample means with unknown population variance, where the standard error is estimated using the sample standard deviation. Compared to the normal distribution, the t-distribution has the degrees of freedom as an additional parameter.

Important 60.2: Degrees of Freedom

“The number of independent pieces of information that go into estimating a parameter is called the degrees of freedom. In general, the degrees of freedom of an estimate of a parameter equal the number of independent individual pieces of information used in the estimate minus the number of parameters that are estimated as intermediate steps in calculating the parameter itself. For example, \(n\) values are used to compute the sample variance. Nevertheless, the degrees of freedom are \(n - 1\), because the mean is estimated as an intermediate step, losing one degree of freedom.”

Degrees of freedom (statistics), by various authors, licensed under CC BY-SA 4.0, retrieved from Wikipedia. 2025

The general probability density function of the t-distribution is:

\[ f(x) = \frac{\Gamma\left(\frac{\nu + 1}{2}\right)}{\sqrt{\nu \pi} , \Gamma\left(\frac{\nu}{2}\right)} \left(1 + \frac{x^2}{\nu}\right)^{-\frac{\nu + 1}{2}} \]

  • \(\nu\) (nu) is the degrees of freedom.
  • \(\Gamma\) is the Gamma function, which for integer arguments \(n\) satisfies \(\Gamma(n) = (n-1)!\).

Since the degrees of freedom for calculating the sample mean is \(n - 1\), it can also be written as: \[ f(x) = \frac{\Gamma\left(\frac{n}{2}\right)}{\sqrt{(n-1) \pi} , \Gamma\left(\frac{n-1}{2}\right)} \left(1 + \frac{x^2}{n-1}\right)^{-\frac{n}{2}} \]

  • \(n\) is the sample size.

The scipy.stats module provides functions to compute the t-distribution:

  • scipy.stats.t.pdf(x, df, loc=0, scale=1) computes the probability density for values x for a t-distribution with df degrees of freedom, mean loc, and standard deviation scale (pdf = probability density function).
  • scipy.stats.t.cdf(x, df, loc=0, scale=1) computes the cumulative probability left of x (cdf = cumulative density function).
  • scipy.stats.t.ppf(q, df, loc=0, scale=1) is the quantile function of the t-distribution (ppf = percentile point function).
  • scipy.stats.t.rvs(df, loc=0, scale=1, size=1) generates size random samples from the t-distribution.

Function parameters can be single values (scalars) or arrays/lists.

As the sample size increases, the t-distribution approaches the normal distribution. A common rule of thumb is \(n > 30\). The graphic below shows the convergence of the t-distribution to the normal distribution.

The maximum of the t-distribution is less dense, but the tails of the distribution are denser than those of the normal distribution.

Thus, for the t-distribution of sample means, we have:

\[ \bar{x} \pm t_{n-1} \cdot \frac{s}{\sqrt{n}} \]

  • \(t\) is the return value of the function scipy.stats.t.ppf(q, df = n - 1, loc = 0, scale = 1)
  • q is the chosen alpha level, or for a two-sided hypothesis test \(\frac{\alpha}{2}\) and \(1 - \frac{\alpha}{2}\).
  • The result is the return value of the functions:
    • scipy.stats.t.ppf(q = alpha/2, df = n - 1, loc = sample_mean, scale = sample_standard_error)
    • scipy.stats.t.ppf(q = 1 - alpha/2, df = n - 1, loc = sample_mean, scale = sample_standard_error)
Tip 60.1: t-distribution or normal distribution?

On a computer, the t-distribution is just as easy (or difficult) to compute as the normal distribution. Since the t-distribution approaches the normal distribution for larger sample sizes anyway, it is recommended to always use the t-distribution.

60.6 Exercise: Confidence Intervals

  1. Estimate the body weight of female penguins of the species Adelie, Chinstrap, and Gentoo observed in the year 2008.

  2. Which confidence interval can you report for the mean values if a confidence level of 90% is required?

Tip 60.2: Tip and Sample Solution

The following steps will help you solve the task:

  1. Determine the sample mean \(\bar{x}\).
  2. Determine the sample standard deviation \(s\), the sample size \(N\), and the standard error \(\frac{s}{\sqrt{N}}\).
  3. Determine the z- or t-values from the normal or t-distribution for the chosen confidence level — for a two-sided hypothesis test use \(\frac{\alpha}{2}\) and \(1 - \frac{\alpha}{2}\).
  4. Compute the confidence interval \(\bar{x} \pm t_{\alpha / 2} ~ \frac{s}{\sqrt{n}}\).
