29  Operations

Pandas, like NumPy, allows vectorized operations, which means calculations on a Series or DataFrame are applied to each element. This allows arithmetic operators to be used directly.

print(27 * "=")
print(temperatures, "\n")

print("Temperatures in Fahrenheit:")
print(27 * "=")
print(temperatures * 9/5 + 32)

29.1 Row- and Column-wise Operations

Pandas includes a wide range of methods that perform arithmetic, summary, boolean, and index functions. A complete reference can be found here: https://pandas.pydata.org/docs/reference/index.html.

By default, these functions are usually applied column-wise. Using the argument axis=1 applies the function row-wise. These methods are also available for Series.

Below, some methods are demonstrated as examples.

29.1.1 Arithmetic Functions

The methods pd.DataFrame.add(), pd.DataFrame.sub(), pd.DataFrame.mul(), pd.DataFrame.div(), pd.DataFrame.floordiv(), pd.DataFrame.mod(), and pd.DataFrame.pow() correspond to the basic arithmetic operators +, -, *, /, //, %, **. They are particularly useful for chained operations.

print("Temperatures in Fahrenheit:")
print(27 * "=")
print(temperatures.mul(9).div(5).add(32))

29.1.2 Summary Functions

  • pd.DataFrame.mean() computes the mean.
  • pd.DataFrame.median() computes the median.

29.1.3 Boolean Functions

Pandas, like base Python, offers various boolean functions.

pd.DataFrame.isin(values) checks for each element in the DataFrame whether it is contained in values. Using the ~ operator, you can check whether elements of a DataFrame are not in values: ~pd.DataFrame.isin(values).
The behavior of the function depends on the data type of the object passed in values.

  • If values is a list or a NumPy array, the result is True if there is a match with any of the contained elements.
  • If values is a Series or a DataFrame, the match is checked positionally (see example).

Tip 29.1: Avoid Surprises

Class-dependent function behavior can distort the results of a data analysis if unnoticed. To prevent this, follow these three general tips:

  1. Check the documentation of the respective function. Python and many modules evolve dynamically, so a function’s behavior can change.

  2. Proceed step by step and use the print() function to inspect intermediate results.

  3. For large datasets, it is often easier to work with custom test data. A ten-row DataFrame with the same data types and structure as your working dataset is easier to manage. Use such a test dataset to verify the functions you plan to use.

29.1.4 Using the .agg() and .apply() Methods

Pandas provides two methods to perform operations row- or column-wise. DataFrame.agg() (or DataFrame.aggregate()) aggregates a DataFrame row- or column-wise using a function. The Pandas method DF.apply() applies a function row- or column-wise to a DataFrame. The methods are very similar and usually produce the same result.

Both functions perform row-wise operations when using the argument axis=1.

29.3 Search and Replace

To determine the index position of a specific value, the NumPy function np.where() can be used. It returns two arrays with the corresponding row and column numbers.

print(np.where(temperatures == 4))
(array([ 1,  2, 11]), array([0, 2, 1]))

Among other locations, the value 4 can be found in row 1, column 0, or in row 2, column 2.

print(temperatures.iloc[1, 0])
print(temperatures.iloc[2, 2])
4
4

Pandas provides two methods to replace values.

  • pd.DataFrame.replace(to_replace, value, *, inplace=False) replaces to_replace with value. Using the argument inplace=True modifies the object directly.

  • pd.where(cond, other=nan, inplace=False) keeps values where cond is True and replaces all other values with other (default is a placeholder for missing values). Using the argument inplace=True modifies the object directly.

The syntax of both functions differs slightly, as shown in the example below.

print(temperatures.replace(to_replace=25, value=1000), "\n")
print(temperatures.where(temperatures == 25, other=1000))

29.5 Sorting

The method DataFrame.sort_index(axis=0, ascending=True, inplace=False) sorts along an axis, by default in ascending order by the index. Passing the argument axis=1 sorts the columns. Using ascending=False sorts in descending order. The argument inplace=True ensures, as usual, that the sorted result is stored directly in the object.

print(temperatures.sort_index(), "\n")
print(temperatures.sort_index(axis=1, ascending=False))
     2021  2022  2023  2024

29.7 GroupBy

The method pd.groupby() splits a DataFrame (or Series) into groups and returns a GroupBy object. The GroupBy object has the same columns and row labels as the original DataFrame, but is organized according to the grouping. Operations applied to the GroupBy object are executed separately for each group.

This can be observed with the guinea_pigs dataset in the following panel.

  1. Tab: The dataset contains 60 entries. The first 30 entries in the column ‘supp’ have the value VC for Vitamin C, and the last 30 entries have the value OJ for orange juice.

  2. Tab: Using the method pd.groupby('supp'), the dataset can be grouped according to the feature values in the column ‘dose’ (0.5, 1, and 2).

  3. Tab: Operations can be applied to the GroupBy object. For example, the column ‘len’ can be selected and the mean length of the tooth-forming cell can be determined using the .mean() method.

  4. Tab: It is also possible to group by multiple features by passing them as a list: pd.groupby(by=['supp', 'dose']).
