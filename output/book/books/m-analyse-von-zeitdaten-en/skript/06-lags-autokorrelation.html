70  6 Lags & Autocorrelation

71 6 Lags & Autocorrelation

Time series differ from classical datasets because observations are not independent.

The value at time t often depends on previous values.

We examine this temporal dependence using:

  • Lags
  • Autocorrelation
NoteNote

Temporal dependence is a core feature of time series. Without it, meaningful forecasting would not be possible.

71.1 6.1 Example Signal

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

rng = np.random.default_rng(21)

t = pd.date_range("2025-01-01", periods=24*14, freq="h")
trend = np.linspace(0, 2, len(t))
season = 0.8 * np.sin(2*np.pi*(t.hour)/24)
noise = 0.4 * rng.normal(size=len(t))

s = pd.Series(15 + trend + season + noise, index=t, name="signal")

s.plot(title="Example Signal")
plt.show()

71.2 6.2 Lag Features

A lag shifts the time series backward.

  • Pandas
  • NumPy (Concept)
lag_1h = s.shift(1)
lag_24h = s.shift(24)

df_lags = pd.DataFrame({
    "y": s,
    "lag_1h": lag_1h,
    "lag_24h": lag_24h
})

lag1 = np.roll(y, 1)

lag1[0] = np.nan
lag24[:24] = np.nan
TipInterpretation

A high correlation between y(t) and y(t-24) indicates a daily periodicity.

71.3 6.3 Calculating Autocorrelation

Autocorrelation measures the correlation between y(t) and y(t-k).

  • Pandas
  • NumPy (Principle)
lags = range(1, 49)
ac = [s.corr(s.shift(k)) for k in lags]

plt.stem(list(lags), ac)
plt.title("Autocorrelation (1–48 hours)")
plt.xlabel("Lag (h)")
plt.ylabel("Correlation")
plt.show()
import numpy as np
import matplotlib.pyplot as plt

y = s.to_numpy()
y = y - np.nanmean(y)

def autocorr(y, k):
    return np.corrcoef(y[:-k], y[k:])[0,1]

lags = range(1, 49)
ac_np = [autocorr(y, k) for k in lags]

plt.stem(list(lags), ac_np)
plt.title("Autocorrelation (NumPy)")
plt.xlabel("Lag")
plt.ylabel("Correlation")
plt.show()

71.4 6.4 Interpretation of Autocorrelation

Typical patterns:

  • Slowly decreasing curve → strong trend
  • Periodic peaks (e.g., at 24, 48, 72) → seasonality
  • Rapid drop toward 0 → weak dependence
WarningWarning

A trend can artificially increase autocorrelation.
If necessary, first detrend or difference the series.
